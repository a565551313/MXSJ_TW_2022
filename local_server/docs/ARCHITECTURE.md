# 独立工程边界

## 决策

本地服与正式服应保持业务行为一致，但不共用运行时包、源码目录、配置、数据库或日志。维护本地服不能顺带修改正式服。此项目独立安装、运行和打包，不使用软链接或运行时复制正式服源码。

## 本次落地

- 包名 `mxsj_local_server`，核心位于 `core/`。
- 从历史提交 `143904e78e68782dc5b824a50e4b8c55f52dc661` 提取曾实现的 SQLite、账号、角色、会话、日志与内部契约，存为本项目拥有的源码；改写命名空间，分离配置与 CLI，并迁入对应测试。
- 这是一次性的历史代码迁入，不是共享包或自动同步机制。保留既有枚举字符串行为及数据库 schema，不在搬迁时改变规则。
- 其他玩法只保留契约／模块边界，协议与传输仍未实现。目录存在不代表功能完成。
- GUI 的 pages、dialogs 是预留目录。当前命令行入口明确使用 console 模式，不伪装成窗口应用。
- 正式服保持恢复后的状态。未来行为一致性须用明确的协议、规则及测试验收，不能以复制目录代替等价验收。

## 验证边界

项目测试禁止导入正式服命名空间，禁止核心导入 Qt；检查启动、构建入口不引用兄弟源码。另将本项目单独复制到临时目录，以隔离 Python 进程验证自检、SQLite 初始化、重开与日志输出。

没有执行真实正式服部署或数据库操作。Windows 窗口、EXE、客户端登录及完整玩法均未验收。
