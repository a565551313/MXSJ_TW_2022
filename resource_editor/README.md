# MXSJ 资源编辑器

梦想世界（MXSJ / Duoyi）客户端 `data/*.fls` 资源包的浏览与编辑工具，
PySide6 GUI，核心解析与界面分离（设计见 [DESIGN.md](DESIGN.md)）。

## 0.3.8：保存与导出安全修复

- 保存（含 Ctrl+S）一律选择**新包路径**，默认建议 `_patched.fls`；
  不再原位覆盖源包，也不再依赖 `.bak` 代替源包保护。
- 拒绝当前源包、历史保存基线和其他已打开包的同路径、硬链接、
  符号链接别名；唯一临时文件构建并校验，通过后原子发布。
  保存失败清理临时文件，原包、旧输出和编辑状态保留。
- 新增条目排序后保存，重建真名缓存；导入时的资源路径按 entry_id
  保留，避免保存后错配旧名称。该保留仅限本次会话，0SLF 本身不存名字。
- 单条/批量/精灵导出都拒绝覆盖源资源及其链接别名；导出路径不能
  经子目录符号链接逃出选定目录，多帧导出先检查全部帧目标。
- 无 Qt / 缺系统图形库时，批量操作测试可以正常收集并跳过 GUI 组。

Linux 核心回归及离屏测试范围见根 `docs/STATUS.md`；Windows 实机与
游戏原生兼容性未在本轮验收，不能把静态检查通过当成实机通过。

## 快速开始（Windows，零折腾）

双击 **`启动编辑器.bat`** 即可：它会自动检查 Python、PySide6、Pillow，
缺什么自动联网安装（官方源连不上会自动换国内镜像），然后打开界面。
启动失败不会闪退，原因会显示在窗口里并写入同目录 `启动日志.txt`。
（前提是电脑装了 Python 3.10 以上且已加入 PATH；没装它会给出下载地址。）

也可以在命令行单独自检：`python bootstrap.py --check-only`。

## 使用方式（目录式工作区）

* 点「设定目录」选择 `.fls` 所在的文件夹（目录里没有 `.fls` 也没关系，
  随后可点「刷新」重新扫描）；左侧文件树只列文件名。
* **双击文件名** → 中间打开该包的缩略图网格，分页浏览（可翻页、
  跳页、选每页 25/50/100/200 条）。
* **单击网格中的条目** → 右侧显示该条目的动画预览与详情（调色板、
  帧列表、大小等）；动画可播放/暂停、拖帧、调帧率、切换帧/画布模式。
* 多个打开过的包会驻留，左侧单击文件名即可来回切换，不重复加载。
* 保存（Ctrl+S）：对当前网格显示的包执行，选新包路径，发布前自动全量校验。

## 功能

* 打开任意 `.fls` 资源包：0SLF 容器（script/skill/skill2/passive/effect/
  magicres5.fls）与 data.fls（名目录式）均可。
* **大文件秒开**：只读包目录建索引（1GB 包实测 0.07 秒、内存约 +14MB），
  条目内容与缩略图按需加载、只生成当前页；保存时未改条目从原文件
  流式拷贝，不经过内存。打开不再全量校验，校验移到保存前自动执行。
* 编辑：PNG 替换精灵帧（编码前给往返误差报告）、原始数据替换、
  条目新增/删除、单条目撤销/还原；保存时临时新包校验 + 原子发布，
  未改动条目逐字节原样保留。
* 导出：单条目（精灵逐帧 PNG、原始文件）与整包精灵批量导出。
* **0SLF 条目真名识别**（0.3.0 起，0.3.1 修复图片引用扒取：真实 .dlg 路径在引号里且反斜杠双写，须反转义后算哈希，否则图片条目认不出名）：0SLF 包内不存文件名（只有路径
  哈希），编辑器用内置 2,901 条布局路径字典对哈希命中命名，并自动
  读已命名的 .dlg 布局、扒出其引用的图片路径反查——interface.fls
  里布局与绝大多数 UI 图片可显示真名（网格显示尾部文件名，悬浮与
  右侧详情看全路径）；从未被引用过的条目无名可认，仍显示"条目 N"，
  打开日志会报"识别真名 X 条"。
* **网格右键菜单 + 多选批量**（0.3.0 起）：条目右键有「导出该条 /
  导出选中 / 导出该页 / 替换（图片·原始）/ 多选导入」；工具条
  「选择」按钮开关多选（按钮实时显示已选数，与"导出选中"联动，
  文件菜单里也有「导出选中…」）。批量导出按真名建目录树（精灵
  导逐帧 PNG、.dlg 导明文、无名条目落 `unnamed/`）；多选导入
  一次选多个文件逐个新增条目（data.fls 会逐个问包内文件名）。
* **按名搜索**（0.3.0 起）：网格工具条搜索框（Ctrl+F 聚焦）输
  `底板800` 这类真名子串即过滤（不分大小写，输序号也可定位，
  与类型过滤叠加生效），顶部信息行显示当前命中条数。
* **按路径导入**（0.3.0 起）：0SLF 的「新增条目 / 多选导入」以及
  右键/编辑菜单的「按路径导入…」都会先问该文件在游戏里的资源
  路径，用路径哈希作条目编号存入——游戏按名字查资源，编号对
  不上就等于没导入。路径已在包中时会提醒并可直接改走替换；
  按路径导入的条目立即带真名显示。与之相对，"替换"只换某个
  已有条目的内容、不改名字，两者别混用。
* **帧图转精灵导入**（0.3.2 起）：编辑/右键菜单「帧图转精灵
  导入…」选一至多张图片（多选按文件名 01、02… 顺序合成多帧
  动画，GIF 自动展开帧），转成游戏精灵字节后按路径导入；锚点
  取左上角，适合界面图与简单动画。与 UI 编辑器「添加新图到
  包」的转精灵是同一格式的两种落点。
* **顶部工具栏**（0.3.5）：常用功能上工具栏（目录/打开/刷新/保存/另存/导出/导入/精灵/删除；图标在上、两字短名在下，与菜单共用同一动作、置灰同步，和 UI 编辑器同一约定）。
* **音频预览播放**（0.3.7）：sound.fls 的 WAV 条目识别为「音频」，预览页显示编码/声道/采样率/时长并可播放/停止、拖进度（解码走系统多媒体后端：PCM/IMA-ADPCM 一般可播，GSM 6.10 等冷门编码取决于系统解码器，播不了时明说并建议导出试听）；切换条目自动停播，无多媒体后端时降级为只看信息不崩溃。
* **真彩精灵 T4/T5 + 导出兜底**（0.3.6）：新增 T4/T5 真彩精灵解码（无调色板、token 后跟 3 字节 RGB，T4 用 u8 行长、T5 用 u16；真实 item.fls 的武器/翅膀图鉴图即此格式，预览与导图可用）。导出精灵解码失败时不再整条丢弃，改落原始字节 `.bin`（原包未覆盖变体可先把样本导出来再补解码，如条目 1163）；无真名的 XOR `.dlg` 布局也按内容识别、导出解密明文 `.dlg`。另确认 interface.fls 中的 `0x1C` 开头条目为 Spine 骨骼二进制（3.4.02/3.6.52）、sound.fls 大条目为整份存入的 RIFF WAV（PCM/GSM610/IMA-ADPCM 三种编码并存），导出时按 `.wav` 落盘可直接播放。
* **保存校验降级**（0.3.4）：写后校验的逐条试解码精灵只对本次
  改动/新增的条目拦截——原包自带而本机解码器未覆盖的精灵变体
  （真实 interface.fls 已有样本）字节原样保留、只在保存日志里
  提示数量，不再把整包保存误拦；逐字字节比对仍是硬闸门。
* **写回目录不变量修复**（0.3.3）：保存时目录恒按条目编号升序
  写出、新增条目的校验种子非零——旧版把新条目追加到目录尾，
  游戏按有序目录寻址会查不到（新图不显示、甚至卡屏）；曾用
  旧版新增过条目的包，用本版打开再保存一次即可修复目录。

## 命令行运行（开发者）

```bash
pip install PySide6 Pillow
PYTHONPATH=src python -m resource_editor ../data          # 以目录打开
PYTHONPATH=src python -m resource_editor ../data/skill.fls # 或直接给包路径
```

或安装后使用入口脚本：`pip install -e .` 后执行 `mxsj-resource-editor`。
`run.py` 是不装依赖、不自检的轻量入口（`python run.py [路径]`），
主要给 PyInstaller 用；日常请走 `启动编辑器.bat` / `bootstrap.py`。

## 打包成 EXE（在 Windows 上执行）

```bat
build_exe.bat
:: 产物：dist\ResourceEditor\ResourceEditor.exe
:: 单文件版： set RESOURCE_EDITOR_ONEFILE=1  然后再跑 build_exe.bat
```

`build_exe.bat`（纯 ASCII、CRLF）依次：探测 `py -3`/`python` → 建或复用 `.venv` →
`pip install -r requirements-dev.txt` → 跑全部 `unittest`（`PYTHONPATH=src`、
`QT_QPA_PLATFORM=offscreen`，不通过就不出包）→
`python -m PyInstaller --noconfirm --clean resource_editor.spec`。spec 把
`src/resource_editor/data/known_paths.txt` 打进 `resource_editor/data/`，与源码里
`Path(__file__).parent.parent / "data"` 的查找方式一致；`console=False`，双击直接开窗。

> 流程与 [`docs/PYTHON_TOOL_CONVENTIONS.md`](../docs/PYTHON_TOOL_CONVENTIONS.md) §4
> 一致。PyInstaller 不能跨平台：Linux 沙箱只做了 spec 干跑（onedir / onefile 都能
> 完整构建出 Linux 产物，数据文件落位正确），**`.exe` 尚未在 Windows 上实际构建和
> 双击验收**（STATUS §3.5）。

## 测试

```bash
PYTHONPATH=src python -m unittest discover -s tests
```

合成夹具覆盖容器读写与编码器、惰性打开（2 万条大包只建索引）、
启动脚本自检；真实包测试在 `data/` 存在时自动启用
（全量 807 精灵解码 + 样本像素级往返 + GUI 离屏冒烟）。

## 约束

* script.fls 条目是 zlib+5 段 XOR 的定制 Python 字节码，只浏览不解码。
* effect.fls 的 41 个未破译二进制条目只提供 Hex 查看，
  背景见 `../tools/data-parser/I0_SPRITE_FORMAT.md`。
* 与原版客户端二进制的最终兼容性需 Windows 原生环境验证。
