# MXSJ 独立脚本编辑器 0.1.0.dev1

**开发基础版（M1），不是完整游戏写包工具，也不是已验收的 Windows 发行版。**
本目录可以独立复制，不在运行时导入 UI/资源编辑器或仓库 `tools`。
Python ≥3.10；GUI 使用 PySide6≥6.4；核心不依赖 Qt。

## 当前具备什么

- 同时打开 `script.fls`（0SLF）和 `data.fls`（FLS\0）的只读索引，区分包来源、候选 VM、
  条目下标与稳定身份；支持 ID/路径筛选、目录项标识与元数据查看。
- **容器识别不等于验证内容是脚本。** 同头的美术包也可能被识别为0SLF；界面明确标候选VM。
  未实现原生模块解码/自动恢复源码；不猜测条目名，也不套 `.dlg` 路径哈希作为导入规则。
- 手工确认来源的 UTF-8 源码，多标签、行号、基础单行高亮、查找、替换全部、撤销/重做、脏标记与关闭提醒。
  参考稿可单独只读打开，禁止保存、修改、关联和编译；不把反编译稿自动升级为可信源码。
- 原子保存源码；源码保存与生成包分离。UTF-8 BOM可读，保存为无BOM的UTF-8；不保持原CRLF/BOM。
- 显式将选中的**文字内容**转换为 Big5 文案或 GBK 路径的转义字节字面量；转换前预览确认。
  选择中不要包含引号/`u`前缀；不可编码直接报错，不替换丢字、不整文件转码。
- `.mxscript.json` 保存**用户手工关联**的包 SHA256、VM、条目下标/身份、源码相对路径；
  不复制包/源码、不保存凭据/编译器路径。打开项目时严格复核指纹和身份，原包变化拒绝套旧项目。
  打开后源包原位变化或同路径替换也拒绝使用旧索引；SHA按需读取并缓存，不解压条目。
- 两套独立标准编译入口：`script → CPython 2.5.6 / b3f20d0a`，
  `data → CPython 2.7.13 / 03f30d0a`。检查精确版本、魔数、位数、exe SHA256；Windows要求x86。
  子进程 `-E -S`，不改PATH，不加载游戏模块，30秒超时；先临时编译再原子发布标准 `.pyc`。
  编译用当前编辑缓冲区，无需先保存。失败保留旧输出，禁止覆盖输入和已知别名。

**仅编译得到标准 `.pyc`，绝不是游戏载荷。不能直接塞进 FLS。**
生成原生新包的入口保持禁用；源码与原模块语义一致性尚未自动验证。

## 启动

Windows 源码目录双击 `启动脚本编辑器.bat`，或：

```sh
python bootstrap.py
python bootstrap.py --check-only
```

自检会补安装 Python3 GUI 依赖，并在官方源失败时提供镜像回退。
已安装PySide6但缺系统Qt动态库时会明确失败并写`启动日志.txt`，不会假报GUI就绪。
`--check-only`不等于旧版编译器/原生游戏验收。

开发环境也可以安装本目录后运行 `mxsj-script-editor`，或：

```sh
PYTHONPATH=src python -m script_editor
PYTHONPATH=src python -m script_editor --version
```

1. 文件 → 打开脚本包索引；同一窗口可同时挂两个包。
2. 打开自己确认来源的源码（必须是UTF-8；含非ASCII的Python2源码还需自己的UTF-8 coding头）。
   来源确认选“否”则只读打开。参考稿不可编译，不能靠改扩展名证明正确。
3. 在源码标签显式选择VM；可关联到选中条目，保存项目用于下次续编。
   项目保存仅保存关联，**不会代替源码保存**。源码/包/项目同一盘时可相对路径整体迁移。
4. 编译 → 检查内置编译器，或显式选择自己安装的标准开发编译器 → 仅编译为标准.pyc。
   M1编译使用源码路径的UTF-8字节作为`co_filename`；尚未复用原模块嵌入文件名。

## 测试与构建

在本目录中：

```sh
PYTHONPATH=src QT_QPA_PLATFORM=offscreen python -m unittest discover -s tests -v
ruff check .
```

真实编译回归须显式设置 `MXSJ_PY25` / `MXSJ_PY27` 为**标准**编译器的绝对路径；未设则跳过对应项，
不能把跳过当作通过。GUI缺Qt动态库时同样明确跳过。全部测试只写系统临时目录/合成包，不改游戏原包。

Windows双击`build_exe.bat`：venv → 依赖 → 测试 → PyInstaller onedir。
输出`dist/MXSJScriptEditor/MXSJScriptEditor.exe`；无参数开窗。
该构建目前只复制空运行时清单，**不是包含两套编译器的正式发行包**。
本轮未构建EXE，也未做Linux冻结干跑；Windows检查清单见仓库开发约定。
