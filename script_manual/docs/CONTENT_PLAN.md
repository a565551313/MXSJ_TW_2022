# 完整开发手册：内容建设与可用性验收

## 原目标不变

让使用者从“我要修改什么功能”查到模块职责、类/函数/关键分支、触发入口、状态与数据流、上下游、布局/配置/资源、修改位置、风险与可追溯证据。源码、独立GUI与离线HTML都要能用；不要求用户拿一份索引自己重做研究。

20篇是首批，不是终点；5135登记和128382函数结构记录不是已解释数量。不会用换首页、加几个按钮或跑绿测试替代内容建设。不承诺损坏/未知候选都能还原成确定结论，未确认必须保留缺口。

## 本次已落实的第一批（dev4）

- 默认任务专题入口与模块字典分开，GUI和离线页共用6份JSON底稿/26步骤。
- 公告：布局与正文分工、刷新节流/地址、两个失败点、写入/内存回退、自动刷新异常形态。
- 登录：首页选服断点、协议条件、输入校验/发送、独立OnLogin与自动登录区别。
- 注册：地区入口、confirm及reg1/2/3/4/5对应、普通提交/结果、验证码与2980独立链。
- 主循环：启动/Loop、网络泵、战斗切换、重登过渡、关闭时点。
- 快捷键：清理/默认/聊天、禁用守卫与战斗方案，不猜原生焦点和按键优先级。
- 战斗队列：S2C构造、过滤/入队、处理函数/取队首、Wait、End普通/录像分支。
- 精确绑定源注释原字节SHA、函数名、证据ID。正文变一字即标专题过期、禁用旧锚点，不把旧叙述接到新源码上。严格来源加载后可直接预览已核行段（至多60物理行，标截断），没核就显示未校验，不暗示读过原文。

这些专题目前仅引用6个已有模块，**不代表20篇已全部串清，更不是5000模块已解释**。A是专题作者，所以全部保持“草稿未独审”；被引用的模块仍各自按原审计状态展示。模块accepted不能自动变成专题accepted。battle四份仍待非A末审。

## 接下来按原五领域逐批做深、扩展

|工作流|下一批具体内容|不能省略的断点|
|---|---|---|
|登录/网络|首页→选服→连接→登录页→提交→成功/错误→返回/重连；解释net/connect/netquicklogin/netserver职责和各自的ProcessServerCmd|不凭同名符号猜调用顺序；服务器接受、原生回调时点与客户端发包分开|
|界面/输入/聊天|默认按钮分发、key与原生输入边界、mainmenu延迟回调、聊天格式/显示/发送与接收|Recall候选异常不修好当原文；焦点/控件类型须有实际依据|
|角色/物品/任务/NPC|角色配置与状态来源、物品点击/使用、任务条件与变化、NPC交互入口及相关面板|不得由名称补成完整玩法；跨模块调用者缺证就先补来源|
|战斗|网络指令到表现/动画/命令对象/播放容器的具体链，继续解释42条名称底稿，处理缺失/损坏|表现与伤害裁决不混；计时/资源释放/协议兼容没有callee证据就不保证|
|全目录扩展|按功能域继续读源、写模块与类函数解释、整理消息/资源/修改指南；批次不止20篇|每批报告新增的实质说明与尚缺范围，不能把自动函数签名计入讲解完成数|

先完成这些真实任务的连贯解释，再按相同标准继续扩域；不把“先做样板”变成长期停在样板。没有可靠来源的模块保留明确缺口，不为了数量编造。

## 每篇专题/模块的实质验收

1. 读者不需要预知脚本名，就能定位该功能入口与适用分支。
2. 说明“为什么改这里”：参数/状态/消息条件、调用方向、布局与配置分工；直接调用、关联线索和未确定连接分别标记。
3. 修改位置可跳到确切函数与证据行段，不只是一个长函数目录；来源改动会失效，不静默继承。
4. 给出可以执行的检查方案、边界/失败用例与风险；没有做过的检查绝不写成实测通过。
5. 覆盖边界明确：专题关联了多少模块/步骤、哪些分支没讲、哪些底稿仍只有名字，不用一个大“完成”掩盖。
6. 作者之外的人按专题原字节SHA做内容审核；这一独立流程尚需补齐，当前专题统一draft，不复用模块审核冒充专题审核。
7. GUI/离线页的交互测试、结构/安全/来源验证与内容审核分开；Windows、原生和服务端仍按实际环境验证。

## 数据、工具和分工规则

- `guides/*.json` 是任务专题唯一底稿；schema的`guide`定义拒绝未知字段/空证据/非法状态。引用使用原包SHA+entry，不以同名路径替代身份。
- `annotations/<domain>/*.json`仍是模块说明底稿，不为刷新专题而重排已审字节。专题不自动宣称任何新的runtime_verified。
- 已审核模块只作为引用来源；A参与写作的专题或模块不由A自批。若正文更新，相关专题须重新阅读/绑定，独立review不自动迁移。
- 不运行恢复模块、不请求业务URL、不恢复1288、不覆盖原包/用户布局、不改游戏或编辑器。不以手册建设为名重建无必要的79MB全量语料。
- 当前未再上传新包；Drive旧test1保留历史，不代表dev4专题版或完整交付。源码推进、内容批次、测试和缺口写STATUS与小报告，阶段提交推送，避免工作只留沙盒。
