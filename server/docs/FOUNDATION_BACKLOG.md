# 非玩法基础能力缺口

这是构建可维护服务端的工程要求，不声称能从客户端归档直接恢复。当前目录只有占位，下面均未实现。

| 责任 | 必须覆盖 |
|---|---|
| 接入与协议 | 握手、拆包粘包、最大长度、编解码、加密版本、超时、背压、限流、模糊测试、连接关闭 |
| 身份与会话 | 密码保护、票据、会话接管、角色归属、旧连接隔离、排队、断线恢复 |
| 运行时 | 状态单写者、实例注册、生命周期、故障隔离、队列容量、超时调度、优雅停机 |
| 数据 | PostgreSQL模型、迁移、事务、幂等、锁顺序、唯一约束、索引、分页、缓存失效 |
| 可靠消息 | outbox、消费去重、重试、死信、事务提交结果未知时的查询恢复 |
| 配置 | 表结构、导入校验、来源标记、版本、规则版本固定、发布和回滚 |
| 经济安全 | 账本、托管、奖励资格、防重复消费、交易/邮件/战斗消费并发、防复制资产 |
| 支付 | 订单、服务端渠道验证、重放防护、补单、退款与对账；不得信任客户端成功通知 |
| 数据恢复 | 备份、恢复演练、快照版本、战斗/实例恢复边界、补偿和资产核对 |
| 运维 | 日志脱敏、指标、追踪、告警、容量压测、健康检查、维护与停服流程 |
| 运营管理 | 权限、审批、审计、封禁、客服、公告、补偿；不能直接绕过业务改在线数据 |
| 测试与协作 | 契约测试、模块测试、真实数据库集成、报文回放、机器人、确定性战斗、CI、代码审查 |
| 多进程与跨服 | 路由、身份范围、状态拥有者代数、故障检测、迁移/重试语义；不能只用Redis锁声称完成 |

具体技术接口由基础设施负责人和相关业务组共同制定，不适合每个玩法组各自实现一份。
