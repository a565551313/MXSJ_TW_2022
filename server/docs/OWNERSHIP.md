# 多人协作与目录所有权

## 1. 不需要一个人实现所有功能

MODULES.md 中 A–I 是可合并或拆分的**职责组**，不是人数要求。
先由团队确定一个集成负责人，再为每个模块填入实际负责人。当前没有虚构账号，也没有生成含假用户的 CODEOWNERS。

| 路径 | 主负责人角色 | 评审要求 |
|---|---|---|
| `modules/<name>/`、`tests/modules/<name>/` | 对应模块负责人 | 普通内部实现本组评审 |
| `modules/<name>/contracts.py` | 对应模块负责人 | 调用方参与，破坏性变更先讨论 |
| `contracts/`、公共配置、依赖清单/锁文件 | 集成负责人 | 受影响模块确认 |
| `bootstrap/`、`runtime/`、`persistence/` | 基础设施组 | 集成负责人 |
| `transport/`、`protocol/` | 接入负责人 | 报文所属业务模块确认；可拆分接入约束见 GATEWAY.md |
| `migrations/` | 数据库集成负责人 | 数据所属模块 + 事务相关方 |
| `game_data/<module>/` | 对应模块负责人 | 配置校验、版本与来源记录 |
| 跨模块测试 | 该用例牵头组 | 依赖方确认 |

目录隔离可以减少文本冲突，不能自动消除语义冲突；接口和事务变更必须评审。

## 2. 依赖规则

- 跨模块只允许导入对方 `contracts.py`，不能访问私有仓储或可变对象。
- `domain/` 不导入连接、ORM、HTTP框架或协议层。
- 业务 `application/` 也不持有 socket/StreamWriter 或导入 transport/protocol 实现；
  回执和定向通知通过公开端口交给接入层，session/owner 路由由 runtime 处理。
- 服务通过 bootstrap 显式注入，不从全局变量寻找其他模块服务。
- 每个模块自己注册到局部清单；全局装配由集成负责人维护。当前尚未实现动态扫描/注册。
- 客户端不控制模块名、方法名或管理命令处理器；协议路由必须白名单。
- 独立开发可提供实现 Protocol 的 fake，但不要改公共接口去适配临时 fake。

## 3. 避免大家抢改同一文件

- 不创建全服统一的巨大 models.py、handlers.py、constants.py。
- 模块常量、数据库模型、私有事件定义放自己的目录。
- 公共错误码只是类别，细分用 `MODULE_REASON`，新增公共枚举由集成负责人整合。
- 迁移脚本由各组提出，数据库负责人解决依赖和分叉；不要每组独立覆盖当前迁移头。
- 发布时同时记录服务代码、配置和数据库 schema 版本。

## 4. 接口调整流程

1. 在本模块说明中写出调用方、变更原因、字段及兼容策略。
2. 调用方确认，再改 contracts.py 与对应测试。
3. DTO 不含连接、ORM实体或共享可变容器；给跨进程序列化预留边界，但不承诺当前支持多进程。
4. 破坏性变更升级契约版本；旧客户端差异留在协议适配器。
5. 合入必须通过架构检查与相关用例测试，不能仅以能 import 作为业务完成标准。


## 5. 补充子系统的分工与生成文件

- 各模块新增 `FEATURES.md`，列出可进一步分给不同负责人的工作包。
- `docs/feature_specs.json` 是共享目录规范，由集成负责人维护；建议变更先在各模块 design/ 提出。
- `docs/features/*.md`、`docs/SUBSYSTEMS.md`、`docs/catalog/*` 为可重建材料索引，不直接在其中维护人工实现进度。
- 各负责人在 `modules/<owner>/design/<feature_id>.md` 保存字段设计、规则证据、问题与进度，代码仍限于自己的责任区。
- 同一一级模块的多个负责人应先确定各自的子目录与公开契约文件归属，不能所有人都改同一个 contracts.py。
- 当前没有声称81个工作包已分配到具体人，也没有声称各子系统接口齐全。

## 6. 可拆分网关的协作规则

[GATEWAY.md](GATEWAY.md) 是下一阶段登录/创角/进图的设计输入，不是额外的玩法模块。
接入负责人负责帧与协议，基础设施负责人负责会话权威、拥有者目录与有限队列，
集成负责人维护公共信封及回送端口；数据库负责人审核会话 fencing 与持久化幂等。
任何团队不得自行复制一份会话代数、实例路由表或资产重试规则。
第一版只装配同进程实现；独立网关启用前须单独验收远程失败、服务身份和状态恢复。
