# 启动组装与生命周期

基础设施负责人维护。当前是工程占位，不包含运行实现。
设计入口：[GATEWAY.md](../../../docs/GATEWAY.md)。

- 第一版显式注入同进程会话、路由、命令投递和回送适配器，不提前部署分布式网关。
- 业务模块不从全局连接表或服务定位器寻找 socket/网关。
- 后续通过装配更换经认证的内部通信适配器；不能修改玩法来弥补远程投递语义差异。
- 启停顺序覆盖停止接收新请求、有界排空、状态保存和会话代数保护。
- 只读复核 API/网页有独立入口，不当作游戏运行时或网关。

GM 启用门槛见 [GATEWAY_SECURITY_GM.md](../../../docs/GATEWAY_SECURITY_GM.md)。
默认不启动管理监听；启用时要求独立身份/MFA、权限、可靠审计与私有网络配置齐备。
游戏/GM/内部入口分别装配白名单和预算；不通过开发模式或缺省密码自动降级安全要求。
