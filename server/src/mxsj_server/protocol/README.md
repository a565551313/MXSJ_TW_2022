# 客户端协议与业务命令适配

接入负责人维护，报文所属模块参与评审。当前仅有 legacy/modern 占位，无编解码实现。
设计入口：[GATEWAY.md](../../../docs/GATEWAY.md)、[INTERFACES.md](../../../docs/INTERFACES.md)。

- 外部 opcode/版本白名单转换成类型化命令，结果由适配器转换回客户端报文。
- 不接受客户端指定模块、处理器、内部节点、授权主体或会话代数。
- 外部线协议与内部通信独立版本化；原协议未验证字段不得从内部 DTO 臆造。
- 首先核查登录→选角→进图及稳定幂等键；旧客户端缺少必要语义时明确改客户端。
- 不导入业务私有实现、不执行原始脚本；原文编码处理只留在协议边界。
