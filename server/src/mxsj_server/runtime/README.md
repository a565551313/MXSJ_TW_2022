# 会话、单写者队列与实例调度

基础设施负责人维护。当前是工程占位，不包含运行实现。
设计入口：[GATEWAY.md](../../../docs/GATEWAY.md)、[INTERFACES.md](../../../docs/INTERFACES.md)。

- 第一版提供同进程会话权威、实体归属目录、有界投递和定向回送适配器。
- session_epoch 隔离旧会话，owner_epoch 隔离旧实例归属，二者不能混用。
- 接管与命令接受有确定顺序；旧队列消息、旧关闭通知必须校验代数。
- mailbox、在途请求与超时有上限；未知执行结果不自动重试有副作用请求。
- 角色/场景/战斗状态不绑定连接或网关进程；远程适配器以后单独实现和验收。

安全扩展见 [GATEWAY_SECURITY_GM.md](../../../docs/GATEWAY_SECURITY_GM.md)：
计划中的 runtime/security 执行已批准限流/访问策略、风险事件与撤销，不做审批或业务资产写入。
玩家、GM、内部调用有独立队列/并发预算；策略版本须可观测，多节点配额不冒充已全局一致。
