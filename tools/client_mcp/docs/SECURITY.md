# 安全与边界草案

> 状态：只读边界已实现；HTTP 仅本机监听并强制 Bearer token。日期：2026-11-02。

## 1. 默认策略

1. 默认只读。
2. 默认本机。
3. 默认测试副本。
4. 默认不接正式服。
5. 默认不记录真实账号、密码、票据、密钥。
6. 默认不允许任意代码执行。

## 2. 禁止事项

- 不提供任意 `eval` / `exec`。
- 不提供任意 shell 命令执行。
- 不执行反编译 / 恢复出来的游戏模块。
- 不绕过客户端保护机制。
- 不修改原始 `data/script.fls`、key DB、`mx.exe`、`mxmain.dll`。
- 不把 MCP 控制通道暴露到公网作为默认配置。
- 不把真实账号凭据写入配置示例、日志、报告或 Git。

## 3. 白名单命令

后续所有受控操作必须登记：

```text
命令名
参数 schema
允许调用阶段
前置客户端状态
是否改变客户端状态
是否需要独占锁
超时
返回字段
脱敏规则
审计字段
Windows 验收证据
```

未登记命令一律返回 `E_NOT_ALLOWED`。

## 4. 会话与锁

MCP Server 必须区分：

- MCP 客户端会话；
- 探针会话；
- 控制锁会话。

只读请求可并发。控制请求必须独占。锁必须有超时和释放机制，避免某个编程工具崩溃后永久占用客户端。

## 5. 鉴权

### 5.1 stdio

stdio 由本机编程工具启动，默认信任本机用户边界，但仍需记录会话来源。

### 5.2 HTTP

当前 HTTP 只允许监听 `127.0.0.1` / `localhost` / `::1`，并强制 Bearer token；非本机监听会被拒绝。未来如果显式开启非本机监听，必须：

- 使用 token 或更强鉴权；
- token 不写入 Git；
- 支持短期 token；
- 记录失败鉴权；
- 限制来源；
- 默认只读；
- 控制类工具需要额外开关。

## 6. 脱敏

日志和报告必须避免：

- 账号；
- 密码；
- 密码摘要；
- 会话票据；
- 快速重登 key；
- 私钥 / 密钥材料；
- 完整聊天内容；
- 真实邮箱；
- 机器敏感标识。

允许记录：

- 测试会话 ID；
- 哈希摘要；
- 模块名；
- 错误类型；
- 状态枚举；
- 地图 ID；
- 控件名；
- 时间戳；
- 脱敏后的参数摘要。

## 7. 审计

每个受控操作至少记录：

```json
{
  "ts": "2026-11-02T00:00:00+08:00",
  "mcp_client": "cursor / claude-code / cline / unknown",
  "session": "session-uuid",
  "tool": "client_invoke_allowed_action",
  "action": "whitelist-action-name",
  "params_digest": "sha256:...",
  "result": "ok / error",
  "error_code": null
}
```

不记录明文敏感参数。

## 8. 输入包安全

用户修改版 `script.fls` 是待核对输入，不是自动可信基线。必须：

1. 记录 SHA-256；
2. 不覆盖仓库原包；
3. 只读解析；
4. 输出差异清单；
5. 确认探针挂点；
6. 生成新测试包；
7. 写后逐条校验；
8. 保留回退路径。

## 9. Mock 边界

根目录 `mock_server.py` / `mock_server_v2.py` 不是完全只读。可能：

- 写 `nocheck`；
- 监听 `0.0.0.0`；
- 写账号 JSON；
- 触发客户端准备流程。

MCP 第一版不默认启动 Mock。未来如需要，必须显式配置隔离测试副本、数据库路径、监听地址和副作用确认。
