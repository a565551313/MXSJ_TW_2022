# phase2-font1：修复已确认的 FONT_EDIT 缺失

## 已定位与本次改动

用户实机日志：account锚点ready、CEDIT工厂ready，取字体时
`step=1 missing_attribute=FONT_EDIT`。不是按钮没接线或布局名字错误。

原生依据：锁定原script.fls的entry4007 `CRegPanel2/CreateEdits` 在pc18/21
读取`interface.FontLT14_3`并传入CEDIT；不是随意选一个字体做fallback。
协议正文实际已经用同一字体显示成功。仅做静态解析，不执行恢复游戏代码。

四个输入框及表单提示区统一使用这个实际原生字体，不依赖旧FONT_EDIT。
提示文字使用原生黑色参数0，与现有四框文字颜色一致，不依赖旧COLOR_EDIT别名。
不向interface注入别名，不改布局字体/位置/控件，不覆盖用户布局或仓库模板。
保留diag2分段日志、缺失属性安全输出与构造失败保留协议的保护。
版本标记改为`phase2-font1`。本包只修确定的字体引用缺陷，不声称全表单已实机通过。

## 安装和验证

1. 退出游戏，只操作测试副本，单独备份当前 `data/script.fls`。
2. 用ZIP里的 `data/script.fls` 替换测试副本的同名文件。
3. **保留你目前编辑后的 interface.fls，不再导入、不改account/CBox。**
4. 打开协议，点一次同意，检查能否进入注册表单；不填真实账号/密码。
5. 若成功，检查四框可输入、密码隐藏、五账号勾选和返回；提交依旧是未接服务端的桩。
6. 若仍失败，只发本次 `photo/register_diag.txt` 最后30行（无photo则工作目录同名）。
   应先出现`phase2-font1`，新的分段日志能定位下一个实际断点，不再混用diag2旧日志。
