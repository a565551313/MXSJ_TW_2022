# 注册布局存储修复（不覆盖原包、不覆盖你的布局改动）

## 为什么编辑器能找到，游戏却没跳转

你给的日志显示条款页原生构造抛 Exception，随后诊断版恢复首页。
没有进入条款文本初始化，也没进入表单。原先“不再冻窗”是你已确认的结果，
但条款跳转仍未通过；不能把回退说成注册页已经修好。

继续检查发现此前写包策略确有缺陷：游戏真实 LoadFile 从 `.dlg` 完整资源
路径算 XOR 密钥，并不会像编辑器那样根据明文头判断“无需解密”。此前说明让
资源编辑器原样导入明文、新布局零密钥写入，都不符合这条原生规则。
这不是要求你再确认一次“有没有导入”，也不是布局地址记忆的问题。

这个助手会先检查你**现在包里**的两条存储状态，再决定是否需要修正。
它不会用仓库模板覆盖你改过的布局，不重排目录，不改布局原文字节、不改脚本。
如果本来已经是正确密文，则不强行修改；还需根据其它原生错误继续排查。

## 使用（测试副本，游戏必须关闭）

1. 解压 `registration_layout_storage_fix.zip` 到可写目录。需要 **Python 3.10+**，
   用资源编辑器时已安装的 Python 即可，不装第三方依赖。不是 EXE。
2. 关闭游戏测试副本。把它**当前实际使用的** `data/interface.fls` 拖到
   `修复注册布局存储.bat` 上。不拖文件夹，不操作原安装目录，不导入默认模板。
   BAT 与 repair_interface_layouts.py 必须仍在同一个目录。
3. 看窗口和工具目录下的 **repair_log.txt**：
   - `plaintext_needs_native_xor`：原先为明文，需要修正；
   - `different_key_needs_native_xor`：可安全解读，但存储密钥不符该路径；
   - `already_native`：已按原生路径密钥存储，该条不改；
   - `output_created: true` / `NEW OUTPUT`：复制并验证完成，输出在输入包旁边，
     通常叫 `interface_native_fixed.fls`；源包从未写入；
   - `NO OUTPUT`：两条都正确，不生成包，请把日志发我继续定位；
   - `FAILED`：没有发布修复包，不换游戏文件。把 repair_log.txt 发我即可。
4. **只有日志确认 NEW OUTPUT 后**，把测试副本原 `interface.fls` 另行备份，
   将生成的新包复制到测试副本 `data/interface.fls`。保持已安装的 diag1
   `script.fls` 不变。不复制到原安装目录，不使用旧的明文导入流程重写两条。
5. 启动测试副本点一次申请会员。若条款页出现，检查拒绝回首页、再次同意进表单。
   不需要输入真实账号资料，更不需要连任何注册服务器。
6. 如果仍不跳转：发工具目录 **repair_log.txt** 和游戏新一次
   **photo/register_diag.txt 最后30行**。旧游戏日志先改名备份，免得混淆。
   不发整个游戏包，不发账号数据库、真实密码或含个人资料的截图。

助手可能复制/逐字检查整个约600MB文件，会有磁盘读写等待；这不是游戏卡屏。
至少预留一个同等大小新包的磁盘空间。原包不能原位覆盖；同名输出已经存在也
拒绝覆盖（另行保留旧输出或用 --output 指定新的文件名再操作）。
为原子独占发布，新包所在磁盘须支持硬链接（通常 NTFS）；FAT/部分云盘目录
不支持时会安全失败。可以在本机可写 NTFS 的测试目录里操作，不要放宽保护。

命令行等效步骤（标准库，无 Qt）：

```text
py -3 repair_interface_layouts.py "D:\游戏测试副本\data\interface.fls"
```

## 保证范围 / 不保证范围

- 仅处理 `login/regterms.dlg` / `login/regform.dlg` 两条。目录/所有其他字节
  逐字对源包核验，输出长度不变；目标按真实路径密钥解开必须等于你现有布局
  明文字节。保留 Big5 文案、GBK 资源路径、空白、MD5 注释和你已做的布局改动。
- 只解析安全 UI_INFO 字面量，不 eval/exec 布局，也不运行原游戏代码；不猜
  损坏内容、不用默认模板补缺失条目。缺地址、无序/重叠目录或非法字面量会拒绝。
- 不改 script.fls，不绕过/移除条款页，不做 overlay，不创建账号或假报成功。
- 只修这一个已找到的原生存储不兼容，不保证用户布局所有控件/皮肤都正确；
  修完是否实际跳转仍须游戏副本验证。23项离线通过不是 Windows/游戏已通过。
- 此版针对台服 v2.27.2 当前仓库镜像。静态依据见 native_dlg_path_cipher.md。

还原：关闭测试游戏，恢复你这次另行备份的 interface.fls；script 不需要改动。
