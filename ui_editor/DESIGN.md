# UI 编辑器设计方案（已确认，2026-10-13）

> **阅读约定（2026-10-18）**：本文同时保留不同版本的设计和演进记录，不是完成清单。当前版本／已实现功能以本目录 [README](README.md) 与源码为准，测试及原生验收范围见 [STATUS](../docs/STATUS.md)；未落实的设计不能据此标为已交付。

## 0.24.0 标尺手动参考线

- **交互入口就是标尺本身**：上标尺向下拖出水平线、左标尺向右拖出垂直线；
  画布 viewport 的事件过滤器负责按住既有线移动，拖回对应标尺删除。新建与
  移动共用一次拖动状态，但只有松手在有效画布区域才提交；离开画布时清预览，
  关闭标尺或切换文档会取消未完成拖动。
- **统一坐标边界**：全局鼠标点先映射到 view／viewport，再交给 `mapToScene()`；
  不在标尺上另写缩放、滚动或 24px 边距补偿。既有线按屏幕 6px 命中，场景绘制
  使用零宽 cosmetic pen，因此缩放后线宽与可点范围保持稳定。
- **状态严格分层**：`LayoutScene._guides_x/_guides_y` 继续只表示拖动控件的临时
  吸附线；手动线另存 scene 坐标，并以 `WeakKeyDictionary` 按 `LayoutDocument`
  保存本次会话的分页状态。它们不是 `Widget.props`，不调用 dirty 或 undo，
  也不进入 `to_dicts()/to_native_dicts()` 与任何 `.dlg` 编码路径。
- **吸附复用同一计算**：`snap_position()` 增加可选的 `guides_x/guides_y`，与既有
  兄弟控件边缘／中线目标合并；未传时旧调用和测试替身接口不变。嵌套控件先经
  `parentItem().mapFromScene()` 转成父相对目标，返回的命中线再映射回场景绘制。

## 0.23.0 Big5 属性提交简转繁

- **字形规范化与文件编码分层**：用户输入先以 Unicode 进入属性编辑器；
  只有当前文档 `text_encoding == "big5"` 时，`core/text_transcode.py`
  才以 OpenCC `s2tw` 转换新提交的显示文字。模型不存 Big5 字节，序列化仍
  由 `dlg_codec` 按字段编码，保存前仍走 `require_save_encoding()`。
- **仅在真实编辑提交边界转换**：`PropertyPanel._commit()` 统一覆盖编辑结束与
  添加属性，不在打开／保存时遍历整份文档；原始提交值等于模型时先直接返回，
  单纯失焦不得把「台」改成「臺」或产生 dirty/undo。真实编辑后的值回灌编辑器，
  再经既有 `changed` 回调刷新画布与撤销历史；即使规范化后等于原模型值，
  也要回灌输入框。来源里的 surrogateescape 码元必须原样保留。
- **字段边界复用 codec**：仅 `sText/sTitle/sTitles/sTips`（含嵌套值）转换；
  `sName` 与资源路径不动，GBK／UTF-8 不做简繁替换。使用 `s2tw` 而非
  `s2twp`，只采用台湾字形标准，不启用地区词彙替换。
- **不允许静默损字**：OpenCC 不认识的 Unicode 原样保留；Big5 无法表示时
  由现有诊断／保存闸门报错，禁止 `errors="replace"` 或退回 GB18030。

## 0.22.1 精灵帧原生画布落点

- 坐标值链不做全局 ±1 补偿：原生保存值、模型绝对坐标与 Qt 场景原点
  已逐层核对一致。小偏差的一条确定来源是精灵像素落点，而不是 `iX/iY`。
- `SpriteFrame` 保留逐帧 `key_x/key_y`，`Sprite` 保留 `center_x/center_y`；
  `AssetResolver` 按格式规格 `(center-key)` 把裁后帧合成到 `canvas_w/h`。
  画布的自动尺寸、对齐、缩略图、切片与动画因此共用同一原生落点。
- 零偏移且帧尺寸等于画布时直接返回原解码图，不额外重绘；普通 PNG/JPG
  路径不变。零尺寸原生画布不拿来覆盖可解码帧，保留原回退。
- **PR #98 复核护栏**：单份精灵输入、帧数、边长、总行数均设上限；预览在
  解码前估算「原始 RGBA＋QImage 副本＋全部原生画布」并以 256 MiB 为界，
  超额直接拒收。画布分配失败不得回退成错位裁后帧。图像调整若遇非零中心
  或不等于最大帧尺寸的透明画布也拒收，因为当前编码器只能写零中心和最大帧尺寸。

## 0.22.0 视口标尺 / 群组手柄 / iFont 即时刷新 / 原生坐标边界

- **标尺独立于网格**：`Ctrl+R` 切换固定的上／左视口标尺，默认关闭；
  开启时才给视口留出 24px 边距，关闭后撤掉。刻度从 `mapToScene()` 的
  可见范围计算，缩放时按 1/2/5 系列选择主刻度，滚动只重绘不搬动画布；
  左上角原点格与两条标尺都是视图的固定子控件，不再往场景四角写数字。
- **群组移动只搬选集的最高层**：多选后拖任一右上角手柄，先排除已有
  选中祖先的后代，避免 Qt 子图元跟随造成二次位移。手柄目标所在子树是
  吸附主项，其余顶层选中项共享它吸附后的实际场景 delta；强制群组移动时
  主项的吸附候选排除同组选中项，避免它们的旧位置把小步拖动拉回去；普通
  拖动候选不变。整次拖动只在松手时 `commit` 一次，零位移不记步。
- **`iFont` 是 `ui.lst` 字体表索引，不是像素字号**：它的整数 spin 改用
  `valueChanged` 即时提交，使文字控件立刻重新查字体表并重绘；其他整数
  属性仍等 `editingFinished`，避免把部分输入过早写成文档。
- **原生坐标只在文件边界转换**：游戏 `.dlg` 的 `iX/iY` 按画布绝对值读，
  `from_native_dicts()` 逐层减去祖先原点；编辑器模型、画布、属性面板、
  撤销和剪贴板继续用父相对值。散装保存、写包与待入包队列统一调用
  `to_native_dicts()` 逐层加回祖先原点。例：A=(500,300)、B 局部=(10,10)，
  画布绝对位置与保存值都是 (510,310)，重开后 B 仍显示局部 (10,10)。
  `from_dicts()/to_dicts()` 保留原内部语义，不能拿它们直接读写游戏文件。
  中间节点缺栏或栏位无效时不补写该栏，但后代换算必须继承最近的有效父绝对
  原点，不能把缺值节点当成 (0,0)，否则重存会重复累加祖先坐标（PR #98 回归）。

## 0.18.0 .igs 导入 / 只保存新资源 / 画布移动手柄

- **`.igs` 挂账语义**（用户确认）：`.igs` 本来就是游戏精灵容器——单张按
  **原字节**挂账，转换勾选对它禁用（再转即破坏）；多张 `.igs` 一次选＝
  各是独立资源，按「目录前缀＋原文件名」逐张挂账，确认框逐行列出最终
  包内路径（前缀默认当前选中项目录、可改）；与普通图片混选直接拒绝，
  与拼名族「整个族只能是 .igs」的既有规矩对齐。
- **「保存新资源」目标决议＝Ctrl+S 同款机制**（用户确认「跟随保存模式」）：
  严格 → 编辑器输出包（没存过问一次路径，**成功后**才记住，与
  `_report_save_target` 时机一致）；宽松 → 就地写原包。写的是**全部**
  挂账（不只被布局引用的），任何布局条目不读不写。成功后
  `doc.source_pack` **迁移**到写出的包：不迁移的话，下一次 Ctrl+S 会从
  原包重新复制整包，把这次写进输出包的新资源悄悄丢掉；但**不调**
  `mark_saved`/`clear_pending`——本次没写布局，布局脏状态与待入包队列
  一概不碰。落盘复用布局保存同一条 `patch_pack_copy_many`（`layouts={}`
  即「只写资源」），替换前回读校验走 `verify_written_pack(res_path=None)`
  （新图逐字节回读＋未改条目逐字节保真），失败/取消目标文件一个字节
  不动；Windows 就地写同样先 `release_pack` 放手柄。
- **移动手柄＝场景级顶层独立图元**（不是控件图元的子级）：子级会被后画
  的兄弟控件盖住，重现「按不到」；顶层＋zValue 置顶保证永远露在最上面，
  位置在控件右上角**外侧**（不盖控件本体）。手柄跟随：选中集变化、
  控件被搬动（itemChange）、属性面板改几何（refresh_widget/refresh_all）、
  锁定切换（apply_lock）都会重对齐；换文档先清账本再 clear()，防悬空。
- **「强制移动」＝ `WidgetItem._force_move` 旗标**：`itemChange` 跳过
  「祖先选中冻结」与「父矩形夹取」两道闸（用户确认根治「长按没反应」的
  两大成因：子 ≥ 父被夹死、父子同选被拒绝），**吸附保留**（Alt 临时
  禁用，与普通拖动一致）；锁定控件不出现手柄、照旧不能拖（用户确认）。
  松手复用 `_commit_if_changed` 记一步撤销；普通拖动路径零改动。
  手柄不是 QObject（QGraphicsItem）：摘除即放手由引用计数回收，
  没有 deleteLater 可调（实测教训，已修）。

## 0.8.4 来源操作与字段编码

`ui/source_actions.py` 独立承接编码切换、刷新、来源布局导出，不继续扩充主窗口。
文档保存 `text_encoding` 与解密后的 `source_bytes`；切换从原始字节解析，
不是对已显示文字做转码。成功保存后更新字节快照；保存/导入预检/诊断/新包回读
沿用文档编码。默认 Big5 的旧 API 保持兼容，资源路径与存储规则不变。
刷新先构造新 resolver、读取新文档与样式，成功才替换窗口状态并关闭旧包；失败
关闭临时 resolver 并保留旧文档。保留包优先级、路径登记、待入包图片，丢弃旧缓存。
树导出锁定节点来源，不用全局同名查找，不通过 serializer，禁止覆盖源资源别名。

## 0.8.3 原生布局写入与连续编辑

core/native_layout.py 是零Qt、自包含原生路径密钥/字面量/XOR模块；它与
core/mxhash.py、core/output_paths.py、core/sprite_format.py 一样，都是仓库
mx_common/ 真源的**字节副本**（tools/devkit/vendor_core.py 生成，勿手改），
交付不依赖仓库兄弟目录，改逻辑改真源后 `--write` 分发、`--check` 校验。新增、原位/迁移替换、重组
回退统一使用路径派生密钥；旧密文头反推只保留读取兼容。_verify_copy 严格按
目标路径密钥回读新布局，与当前序列化明文逐字比对，错误输出不得发布。
来源：notes/native_dlg_path_cipher.md 的实际LoadFile方法表及静态调用链。
明确保存当前布局会迁移旧零/错误密钥；未改布局保持原字节，所有原包保护不变。
保存清单/成功提示说明原生存储迁移；没有改动也可保存回新包，不强迫用户造改动。

## 0.8.2 真实地址记忆和只读恢复

成功写包/按路径回读后，把用户提供的有效相对 .dlg 路径写入 QSettings；
新实例启动加载到 resolver，再与每个包的实际 ID 相交。不记失败或未落盘导入，
不改变 0SLF 格式、不建立包外项目文件。应用设置不是可迁移的全名恢复索引。
包根新增“按包内路径打开布局”，精确包/地址只读解析成功才入树和记忆。
注册两张已知布局路径入内置字典，用于旧版包恢复；不把 basename 等同完整地址。

  单一待入包叶子不冒充源包资源，切换清掉；已有内容/空列表分别是替换/新增基线。
- `patch_pack_copy(..., allow_create=True)` 显式启用新增；默认缺条目仍拒绝。
  新增/替换均按原生路径密钥（0.8.3更正旧明文/沿任意原密钥策略）；新编号有序插入、
  非零种子，病态目录回退重组。发布前独立读取并逐字节验证未改负载、目标布局、
  附加图片和预期编号集合，最后原子发布。新增布局计入 GUI 的编号/数量校验。
- 保存成功才清待入标记、优先挂载新包并登记本会话路径；树双击严格锁定节点
  对应的包，不按跨包同名顺序冒取。自定义路径仅本会话识别，不承诺重启反推。
- 不自动导图片/接脚本，不扩为待入包队列。新增布局的客户端加载、Windows
  桌面/EXE、完整语料库仍待验；包结构/工具回读不是原生实机验收。


## 0.8.0 引用护栏、诊断与保存清单

- `core/diagnostics.py` / `core/review.py` 零 Qt、只读：按树路径定位诊断，
  以静态 `LayoutLink` 提供引用影响；资源存在性由调用方注入，未挂载不伪报缺图。
- PropertyPanel 的同步 `before_change` 在 props 写入/changed 信号之前运行，
  提交与添加属性覆盖共用；核心字段不能移除。删除确认枚举全部后代并尊重锁定。
  不改索引/字节码，不改原生字段之外的任何项目格式。
- LayoutDocument 深拷贝最近成功保存基线；清单按树位置比较所有属性，重排
  表现为位置差异，不靠操作日志推测。成功保存保留 UI 撤销历史、断开同字段
  合并键；撤销到已保存基线可恢复干净状态。失败/取消不迁移基线。
- GUI 确认列布局、图片新增/替换/跳过、全部静态风险；面板会话隐藏项不影响
  保存检查。原生 Big5/GBK 编码错误阻止确认，程序化窗口写回也先检查编码；
  低层 codec 的兼容回退不改，不能据此宣称引擎支持新字符。
- 诊断不构成引擎裁剪/动态脚本真值：零尺寸可能是自动尺寸，越界/缺资源/缺
  控件引用只警告。保存后解析器来源自动迁移仍属已有独立待验风险。

## 0.7.1 安全约定

写包输出不得是源包或任一挂载包的别名；独占临时副本构建后，
发布前回读布局/附加资源，并逐字节比较未改条目。通过后原子发布新包，
失败清理临时文件且保留旧输出。原位补丁只作用于独占临时副本，
不再向用户提供原位覆盖源包的选项。

## 关键约定

* **绘制只做「材料可复现」，判定交给人**：`ui/paint_samples.py` 渲染样例与
  清单，`tools/render_paint_samples.py` / `tools/paint_compare.py` 提供 CLI，
  结论写进 `docs/PAINT_CHECKLIST.md`（未核对留空，机检见
  `tests/test_paint_samples.py`）。
* **写回校验与窗口解耦**：`core/publish.py` 承担「新包算不算写成功」的全部
  判定（条目数/目录升序/集合/二分命中/未改条目保真/全新解析器回读）与保存前
  检查（编码闸门、图片清单、待入包提示）；`main_window.write_pack_copy` 只做
  编排与状态迁移，回读钩子由窗口注入（测试注入只读 FlsPack 版）。
  反例逐条见 `tests/test_publish.py`（20 例，零 Qt）。
* **保型往返是硬门槛**：2,706 个已解密 `.dlg` 全部须通过
  「解析 → 序列化 → 再解析」结构一致性测试（list/tuple/bool/
  float/中文字符串都不许丢型或丢字）。
* 控件属性以原始字典保存，未知字段原样保留；属性面板按值类型
  生成编辑器，嵌套结构只读展示，字段可增删。
* 尺寸约定：`iWidth/iHeight` 为正用之，为 0 取图片首帧尺寸
  （网格类按行列推算），再不行用兜底尺寸；编辑器内坐标相对父控件，
  原生 `.dlg` 读写边界换算为画布绝对坐标（见 0.22.0）。
* 绘制近似边界：`CPngNineFrame` 用**固定三分**做九宫格（切割线不可配，
  见 README「格式与保真约定」与 `notes/ui_editor_phase2_design.md` §2.3），
  其余控件按类型近似；精确绘制以进游戏比对为准。
* 资源按引擎方式寻址：多包并挂、路径哈希查表；缺图画占位框，
  不挡编辑。精灵绘制取首帧（按钮常态），多状态帧放二期。
* 保存写散装 `.dlg`（原版式、MD5 行重算；显示文本 Big5 与资源路径 GBK 混合编码，按字段编解码）；二期 M1 起可「保存回资源包（生成新包）」：按原生路径 XOR 密钥新增/替换、严格原生回读及逐条校验、原包不动（tools/ui_pack_write_probe.py 已在真实 script.fls 上验证）；0.2.1 起写回走快速补丁（core/pack_build.patch_pack_copy：新包=复制+原位补丁、变长条目迁移至目录原址、仅病态交叠包回退整包重组），校验同步利用"他条 span 不变"跳过读取，大包保存秒级。
* 样式表 `ui.lst` 可从已挂载包自动加载，或手动指定文件；
  `iFont`/`iStyle` 分别索引字体表与 TBStyle。
