# UI 编辑器设计方案（已确认，2026-10-13）

## 0.8.3 原生布局写入与连续编辑

core/native_layout.py 是零Qt、自包含原生路径密钥/字面量/XOR模块；它与
core/mxhash.py、core/output_paths.py、core/sprite_format.py 一样，都是仓库
mx_common/ 真源的**字节副本**（tools/devkit/vendor_core.py 生成，勿手改），
交付不依赖仓库兄弟目录，改逻辑改真源后 `--write` 分发、`--check` 校验。新增、原位/迁移替换、重组
回退统一使用路径派生密钥；旧密文头反推只保留读取兼容。_verify_copy 严格按
目标路径密钥回读新布局，与当前序列化明文逐字比对，错误输出不得发布。
来源：notes/native_dlg_path_cipher.md 的实际LoadFile方法表及静态调用链。
明确保存当前布局会迁移旧零/错误密钥；未改布局保持原字节，所有原包保护不变。
保存清单/成功提示说明原生存储迁移；没有改动也可保存回新包，不强迫用户造改动。

## 0.8.2 真实地址记忆和只读恢复

成功写包/按路径回读后，把用户提供的有效相对 .dlg 路径写入 QSettings；
新实例启动加载到 resolver，再与每个包的实际 ID 相交。不记失败或未落盘导入，
不改变 0SLF 格式、不建立包外项目文件。应用设置不是可迁移的全名恢复索引。
包根新增“按包内路径打开布局”，精确包/地址只读解析成功才入树和记忆。
注册两张已知布局路径入内置字典，用于旧版包恢复；不把 basename 等同完整地址。


## 0.8.1 单文档布局导入

- `core/layout_import.py` 零 Qt 预检：完整相对 .dlg 路径、受限字面量解析、
  Big5/GBK 原生字段严格编码；目标已有则验证是布局，不覆盖任意同编号资源。
- 包根右键导入；无已识别布局包仍入树。通过预检与替换/丢弃确认才切文档。
  `pending_pack_import` 与内容 dirty 分离：撤销/散装导出不能抹掉待入包标记。
  单一待入包叶子不冒充源包资源，切换清掉；已有内容/空列表分别是替换/新增基线。
- `patch_pack_copy(..., allow_create=True)` 显式启用新增；默认缺条目仍拒绝。
  新增/替换均按原生路径密钥（0.8.3更正旧明文/沿任意原密钥策略）；新编号有序插入、
  非零种子，病态目录回退重组。发布前独立读取并逐字节验证未改负载、目标布局、
  附加图片和预期编号集合，最后原子发布。新增布局计入 GUI 的编号/数量校验。
- 保存成功才清待入标记、优先挂载新包并登记本会话路径；树双击严格锁定节点
  对应的包，不按跨包同名顺序冒取。自定义路径仅本会话识别，不承诺重启反推。
- 不自动导图片/接脚本，不扩为待入包队列。新增布局的客户端加载、Windows
  桌面/EXE、完整语料库仍待验；包结构/工具回读不是原生实机验收。


## 0.8.0 引用护栏、诊断与保存清单

- `core/diagnostics.py` / `core/review.py` 零 Qt、只读：按树路径定位诊断，
  以静态 `LayoutLink` 提供引用影响；资源存在性由调用方注入，未挂载不伪报缺图。
- PropertyPanel 的同步 `before_change` 在 props 写入/changed 信号之前运行，
  提交与添加属性覆盖共用；核心字段不能移除。删除确认枚举全部后代并尊重锁定。
  不改索引/字节码，不改原生字段之外的任何项目格式。
- LayoutDocument 深拷贝最近成功保存基线；清单按树位置比较所有属性，重排
  表现为位置差异，不靠操作日志推测。成功保存保留 UI 撤销历史、断开同字段
  合并键；撤销到已保存基线可恢复干净状态。失败/取消不迁移基线。
- GUI 确认列布局、图片新增/替换/跳过、全部静态风险；面板会话隐藏项不影响
  保存检查。原生 Big5/GBK 编码错误阻止确认，程序化窗口写回也先检查编码；
  低层 codec 的兼容回退不改，不能据此宣称引擎支持新字符。
- 诊断不构成引擎裁剪/动态脚本真值：零尺寸可能是自动尺寸，越界/缺资源/缺
  控件引用只警告。保存后解析器来源自动迁移仍属已有独立待验风险。

## 0.7.1 安全约定

写包输出不得是源包或任一挂载包的别名；独占临时副本构建后，
发布前回读布局/附加资源，并逐字节比较未改条目。通过后原子发布新包，
失败清理临时文件且保留旧输出。原位补丁只作用于独占临时副本，
不再向用户提供原位覆盖源包的选项。

## 决策记录

| 议题 | 结论 |
|---|---|
| 功能深度 | 独立 **UI 编辑器工具**：编辑现有布局 + 从零新建布局；一期 = 编解码 + 渲染 + 画布编辑 + 新建 + 保存 + PNG 导出；撤销/重做、按钮多状态与九宫格像素级绘制、回写 .fls 放二期 |
| 工程位置 | 仓库顶层 `ui_editor/`，与 `resource_editor/` 平级，src 布局 + pyproject，自包含可独立运行 |
| 打开来源 | 散装 `.dlg`（文件/目录）+ 从 `interface.fls` 按路径直开（路径哈希 + XOR 解密），两种都要 |
| 语言 | 中文 UI + 中文注释；PEP8（ruff，行宽 88） |

│   ├── dlg_codec.py            # .dlg 文本 ⇄ 字典列表（保型往返）
│   ├── model.py                # 控件树模型 + 新建工厂
│   ├── defaults_data.py        # 38 类控件默认模板（全量普查生成）
│   ├── styles.py               # ui.lst 样式表解析
│   ├── assets.py               # 多包/散装资源解析（QtGui）
│   └── painters.py             # 38 类控件近似绘制规则（QtGui）
└── ui/                         # PySide6 界面
    ├── main_window.py          # 主窗口与工作流
    ├── commands.py             # 编辑命令 mixin（添加/粘贴/删除/锁定/右键）
    ├── workflows.py            # 文件/资源包打开、导入、保存、导出 mixin
    ├── window_setup.py         # 面板/菜单/工具栏/信号组装 mixin
    ├── canvas.py               # 画布场景/图元（选中/拖动/缩放）
    ├── property_panel.py       # 属性面板（按值类型生成编辑器）
    ├── panels.py               # 布局文件树 / 控件树 / 调色板

## 关键约定

* **绘制只做「材料可复现」，判定交给人**：`ui/paint_samples.py` 渲染样例与
  清单，`tools/render_paint_samples.py` / `tools/paint_compare.py` 提供 CLI，
  结论写进 `docs/PAINT_CHECKLIST.md`（未核对留空，机检见
  `tests/test_paint_samples.py`）。
* **写回校验与窗口解耦**：`core/publish.py` 承担「新包算不算写成功」的全部
  判定（条目数/目录升序/集合/二分命中/未改条目保真/全新解析器回读）与保存前
  检查（编码闸门、图片清单、待入包提示）；`main_window.write_pack_copy` 只做
  编排与状态迁移，回读钩子由窗口注入（测试注入只读 FlsPack 版）。
  反例逐条见 `tests/test_publish.py`（20 例，零 Qt）。
* **保型往返是硬门槛**：2,706 个已解密 `.dlg` 全部须通过
  「解析 → 序列化 → 再解析」结构一致性测试（list/tuple/bool/
  float/中文字符串都不许丢型或丢字）。
* 控件属性以原始字典保存，未知字段原样保留；属性面板按值类型
  生成编辑器，嵌套结构只读展示，字段可增删。
* 尺寸约定：`iWidth/iHeight` 为正用之，为 0 取图片首帧尺寸
  （网格类按行列推算），再不行用兜底尺寸；坐标相对父控件。
* 绘制近似边界：`CPngNineFrame` 用**固定三分**做九宫格（切割线不可配，
  见 README「格式与保真约定」与 `notes/ui_editor_phase2_design.md` §2.3），
  其余控件按类型近似；精确绘制以进游戏比对为准。
* 资源按引擎方式寻址：多包并挂、路径哈希查表；缺图画占位框，
  不挡编辑。精灵绘制取首帧（按钮常态），多状态帧放二期。
* 保存写散装 `.dlg`（原版式、MD5 行重算；显示文本 Big5 与资源路径 GBK 混合编码，按字段编解码）；二期 M1 起可「保存回资源包（生成新包）」：按原生路径 XOR 密钥新增/替换、严格原生回读及逐条校验、原包不动（tools/ui_pack_write_probe.py 已在真实 script.fls 上验证）；0.2.1 起写回走快速补丁（core/pack_build.patch_pack_copy：新包=复制+原位补丁、变长条目迁移至目录原址、仅病态交叠包回退整包重组），校验同步利用"他条 span 不变"跳过读取，大包保存秒级。
* 样式表 `ui.lst` 可从已挂载包自动加载，或手动指定文件；
  `iFont`/`iStyle` 分别索引字体表与 TBStyle。
