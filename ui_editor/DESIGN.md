# UI 编辑器设计方案（已确认，2026-10-13）

## 决策记录

| 议题 | 结论 |
|---|---|
| 功能深度 | 独立 **UI 编辑器工具**：编辑现有布局 + 从零新建布局；一期 = 编解码 + 渲染 + 画布编辑 + 新建 + 保存 + PNG 导出；撤销/重做、按钮多状态与九宫格像素级绘制、回写 .fls 放二期 |
| 工程位置 | 仓库顶层 `ui_editor/`，与 `resource_editor/` 平级，src 布局 + pyproject，自包含可独立运行 |
| 打开来源 | 散装 `.dlg`（文件/目录）+ 从 `interface.fls` 按路径直开（路径哈希 + XOR 解密），两种都要 |
| 语言 | 中文 UI + 中文注释；PEP8（ruff，行宽 88） |

## 架构

```
src/ui_editor/
├── app.py / __main__.py        # 入口
├── core/                       # 零 Qt 依赖部分可无头测试
│   ├── errors.py               # 统一异常
│   ├── mxhash.py               # 引擎路径哈希（与 tools 复刻同源）
│   ├── pack.py                 # 0SLF 只读容器（惰性索引 + 按哈希查表）
│   ├── sprite.py               # I0/T0/I1 精灵解码 → RGBA（无 Pillow）
│   ├── dlg_codec.py            # .dlg 文本 ⇄ 字典列表（保型往返）
│   ├── model.py                # 控件树模型 + 新建工厂
│   ├── defaults_data.py        # 38 类控件默认模板（全量普查生成）
│   ├── styles.py               # ui.lst 样式表解析
│   ├── assets.py               # 多包/散装资源解析（QtGui）
│   └── painters.py             # 38 类控件近似绘制规则（QtGui）
└── ui/                         # PySide6 界面
    ├── main_window.py          # 主窗口与工作流
    ├── canvas.py               # 画布场景/图元（选中/拖动/缩放）
    ├── property_panel.py       # 属性面板（按值类型生成编辑器）
    └── panels.py               # 布局文件树 / 控件树 / 调色板
```

## 关键约定

* **保型往返是硬门槛**：2,706 个已解密 `.dlg` 全部须通过
  「解析 → 序列化 → 再解析」结构一致性测试（list/tuple/bool/
  float/中文字符串都不许丢型或丢字）。
* 控件属性以原始字典保存，未知字段原样保留；属性面板按值类型
  生成编辑器，嵌套结构只读展示，字段可增删。
* 尺寸约定：`iWidth/iHeight` 为正用之，为 0 取图片首帧尺寸
  （网格类按行列推算），再不行用兜底尺寸；坐标相对父控件。
* 资源按引擎方式寻址：多包并挂、路径哈希查表；缺图画占位框，
  不挡编辑。精灵绘制取首帧（按钮常态），多状态帧放二期。
* 保存一期只写散装 `.dlg`（原版式、MD5 行重算；显示文本 Big5 与资源路径 GBK 混合编码，按字段编解码）；回写包
  内需整包重建 + 原条目 XOR 密钥，放二期。
* 样式表 `ui.lst` 可从已挂载包自动加载，或手动指定文件；
  `iFont`/`iStyle` 分别索引字体表与 TBStyle。
