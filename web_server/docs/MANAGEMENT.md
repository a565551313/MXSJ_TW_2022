# 管理器与独立监听设计 0.3.0

## 分层与进程

GUI／Web API 调用同一个 Manager。桌面动作通过 QThreadPool 执行，HTTP 服务使用有界线程。
第一版一个管理器进程持有一个管理目录的 OS 锁，不是跨机器集群控制平面。
SQLite 只存 Web 草稿、设置、不可变文本版本、管理员密码哈希和操作审计，不连接游戏业务数据库。
监听启动状态不持久化；启动 GUI 时两者都停止，headless 只有显式 enable-admin 才开启管理入口。

公开服务暂停保留端口但新请求返回503；管理后台暂停保留查看、预览、登录和退出能力，禁止写入。
停止关闭监听；已有短请求限时完成，3秒后关闭残留连接，主监听线程限时等待。
暂停／停止不撤销之前合法接受并已提交的操作。停止后台清除全部会话，重新启动不会复活旧 Cookie。
本地操作优先拥有后台开关，不等于强行中断已提交事务。并发操作按生命周期锁和状态锁顺序执行。

## 配置生效

- host/port/origin：下次启动采用；界面同时展示 configured 与 active_config，防止把保存当成已切换。
- ACL、可信代理、每分钟限流：保存后立刻应用；远程可能锁住自己，UI 提示，本地不受网络 ACL 限制。
- 只支持一个管理员身份，local/admin 用于审计来源，不冒充多人账号体系、MFA 或分级 RBAC。
- 密码仅本地初始化／重置；数据库权限和本机 OS 权限是本地管理的信任边界。

## 反向代理（部署要求，不是自动配置）

DNS 指向服务器；公开域名与后台域名分别代理到独立端口。
管理 origin 必须与浏览器实际地址完全一致（协议／域名／端口）；代理保留 Host，正确处理 Origin，覆盖／追加可信 X-Forwarded-For。
HTTPS 在代理终止；HTTPS 后台仅接受真实 socket 来源位于 trusted_proxies 的请求，未配置可信代理时拒绝访问；默认绑定回环。配置 HTTPS origin 本身不会提供 TLS。
代理必须限制请求头／body／并发、慢连接、TLS 协议版本和公网速率；本程序不是抗 DDoS 产品。
当前为标准库 HTTP/1.0 有界监听，不支持 TLS、HTTP/2、WebSocket、上传更新包、Range 下载或跨副本原子发布。
旧客户端 TLS、gzip/chunked、缓存／304 行为未原生验证，部署时不得无依据启用协议变换。

## 日志与持久化

state、release 和对应内容管理审计在同一 SQLite 提交；失败不切换公开内存快照。
提交之后文件诊断失败只告警，不回报业务回滚。监听／登录等诊断不是事务审计，不能宣称全程无缺口。
日志仅写受限事件、服务、来源IP、允许路径、状态及耗时；未知路径不记录原文，query/headers/body不进入文件。
后台可导出脱敏诊断和最近500条数据库审计；日志页显示最近1000条内存诊断，历史文件在本地日志目录。
诊断轮替5MiB/5备份；审计无自动删除。SQLite 数据文件、日志和锁均位于私有管理目录，目录必须可信。
不保证抵御同机高权限攻击者、恶意并发换路径、磁盘物理损坏或操作员篡改；备份／恢复由操作员离线执行。

## 客户端与管理 UI 验收边界

两类界面不混淆：玩家客户端读取 Big5 文本；现代浏览器后台使用 UTF-8 HTML/JSON。
后台 CSP 限制外部资源与脚本，内容通过 textContent／控件 value 显示，不执行公告HTML。
本地GUI预览同样是纯文本，不是游戏渲染。发布文件的算法测试和本地HTTP测试不代表真实Windows客户端通过。

Windows 必验：中文空格路径、初次启动依赖、1.25×/1.5× DPI、工具栏分组、最小化托盘恢复、托盘菜单一致性、
取消／隐藏／退出三种关闭行为、暂停继续、端口冲突、浏览器断开／重连、停止后台后Cookie失效、退出无残留线程、两种EXE。
当前沙盒无Qt原生libGL，相关GUI测试明确跳过；浏览器脚本做语法检查，未声明浏览器端完整交互已验收。
