发布管理
先保存草稿，再生成不可变版本；发布和回退均为切换已生成版本。
原生更新清单、补丁包、断点续传：尚未实现，不提供假成功操作。


服务设置与访问控制
高级设置以 JSON 编辑；服务监听变更需重启对应服务，名单立即生效。模式：allow 不限制；black 拒绝黑名单；white 仅允许白名单，拒绝优先。
规则格式：{"cidr":"192.0.2.0/24","note":"说明","expires":0}；expires 为 Unix 秒，0 永久。可信代理只填实际受控代理地址。
错误白名单可能锁住远程访问，本地 GUI 始终可修正；HTTPS 域名配置不会自动安装证书或修改 DNS。


日志与审计
文件日志 5 MiB × 5 备份；数据库操作审计单独保存，不宣称防篡改。
