# 观察器操作步骤（给不熟悉命令行的人）

> 草稿。目前只能在你的电脑上运行，我无法替你测试。遇到报错，把屏幕上的文字发给我即可。

## 准备（只做一次）
1. 下载 **32 位** Python 3（python.org 下载页里标注 "32-bit" 的 Windows 安装包）。游戏 mx.exe 是 32 位，必须用 32 位 Python。
2. 安装时勾选 "Add python.exe to PATH"。
3. 打开"命令提示符"（开始菜单搜索 cmd），输入下面一行并回车：
   ```
   python -m pip install frida
   ```
   如果提示网络错误或找不到 frida，把提示发给我。

## 放置文件
4. 在游戏目录外建一个文件夹，例如 `D:\Lager\观察器\`，把 `observe.js` 和 `observe.py` 放进去。不要放进游戏目录，也不要改游戏文件。

## 运行
5. 先启动游戏 mx.exe，**先不要点登录**。
6. 在 cmd 里进入观察器目录：
   ```
   cd /d D:\Lager\观察器
   ```
7. 运行：
   ```
   python observe.py mx.exe
   ```
8. 窗口里应出现 `hooked` 的提示。如果 IMP_ 相关函数显示 `missing`，把窗口内容发给我。
9. 回到游戏，选择服务器、点击登录，等 1 到 2 分钟（看到“正在连接服务器”即可）。
10. 回到 cmd 窗口，按 Ctrl+C 停止。
11. 把同目录下生成的 `observe-log.jsonl` 文件发给我。

## 注意
- 如果游戏启动后直接退出，或者观察器报错，停止操作，把报错文字发给我。
- 这个工具只记录，不会改包、不会改密钥、不会连接外部服务器。
