# 并行任务协调表（2026-10-10）

**协调者**：主会话（只负责分派、收结果、合并、更新 workitems/timeline，不做逐项分析）。
**执行者**：每份任务书由一个独立会话执行，产出写入本目录的同名 `*-result.md`。

## 通用规则（所有执行者必须遵守）
1. 只读：不修改 `mx.exe`、`mxmain.dll`、`IMProtocol.dll`、`server.ini` 等游戏文件，不修改 `tools/` 下的代码。
2. 不运行游戏、不连接任何网络地址（离线、只读静态分析）。
3. 结论分级：凡是只有推断、没有字节或反汇编依据的，一律写“未证实”，并写明依据。
4. 每个结论都要给出地址（如 `0x10001770`）或文件与行号作为依据。
5. 不删除任何文件；不使用 `git rm`。
6. 结果文件写完后告知协调者，协调者统一提交。

## 记录要求（每位执行者必须做到，合并前协调者会检查）
每份 `*-result.md` 文件开头必须包含以下信息，缺一项则结果视为不完整：
1. **执行者与会话**：会话或 agent 名称、开始和结束时间（含时区）。
2. **输入校验**：读取的每个文件的路径和 sha256（或 md5）。例如 `IMProtocol.dll` 的 sha256 要写出来，便于确认版本一致。
3. **工具与版本**：Python 版本、capstone 版本、反汇编工具名与版本。
4. **执行步骤**：按顺序列出实际执行的命令或操作（可以附在结果文件末尾的代码块里），以便别人能复现。
5. **地址与依据表**：每个结论对应的地址、文件与行号。
6. **未完成与未证实**：列出没有验证的内容，以及需要什么证据才能验证。
7. **修改记录**：确认本次没有修改任何游戏文件、工具代码或已有文档（如有例外，必须写明）。
