## 3. 未完成的原因

1. **指令边界不可靠**：未知字节的尺寸（1B/3B）本身未定；按错误尺寸切分会使后续全部错位（表中已有“post-desync cascade”记录）。
2. **多变体 S 盒**：同一字节在不同 code object 含义/尺寸不同（0x6C 已证实）。统计必须按 code object 分组，而不是全局计数。
3. **时间与算力**：v7 重试（870 条）在 2 核上耗时约 3.5 小时（含与其它任务并行的争用），不适合在同一会话内对 16 个字节做多轮假设检验。
