## 📋 任务背景

经过任务A的努力，我们已经破解了梦想世界的加密算法、帧格式、登录流程和部分命令。现在需要将所有发现整理成一份**完整、规范、可查阅的协议文档**，作为整个项目的核心交付物。

## 🎯 具体目标

1. 整理所有已知的协议命令及其数值
2. 定义完整的包格式规范
3. 绘制协议状态机
4. 编写类似 RFC 格式的协议规范文档
5. 提供抓包示例和解析工具

### 步骤2: 定义包格式（1天）

**线上帧格式**（已破解）:
```
[加密( uint16_be(总长度) + payload )]
```

**Payload 格式**（推测，需验证）:
```
+----------------+------------------+-----------------+
|  命令字 (2字节) |  包体长度 (2字节) |  包体数据 (N字节) |
+----------------+------------------+-----------------+
```

**包体数据格式**（从 netserver.py 推测）:
- `PacketAddI(value)` → int32 (4字节，小端序?)
- `PacketAddUI(value)` → uint32 (4字节)
- `PacketAddL(value)` → int64 (8字节)
- `PacketAddS(string)` → 长度前缀字符串?
- `PacketAddBinaryS(data)` → 长度前缀二进制
